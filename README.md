# Lead Management System

## Overview

A web-based Lead Management System developed using Django,
Django REST Framework, Microsoft SQL Server, Bootstrap 5,
JavaScript and Chart.js.

## Features

- User Authentication
- Product Management
- Region Management
- Lead Management
- CRUD Operations
- Product Bulk Upload
- Region Bulk Upload
- Lead Bulk Upload
- Product Export
- Region Export
- Lead Export
- Search and Filtering
- Lead Analytics
- Product Analytics
- Region Analytics
- Dashboard
- REST APIs

## Technologies Used

- Python
- Django
- Django REST Framework
- Microsoft SQL Server
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js
- Pandas
- Git & GitHub
